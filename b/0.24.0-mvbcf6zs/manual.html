2. 描く

  1. サイドバーのブラシを選びます(はじめから選ばれています)。
  2. キャンバスの上でなぞると線が引けます。
  3. 消したいときは消しゴムを選んでなぞります。

ペンタブレットや Apple Pencil では、筆圧で線の太さや濃さが変わります。マウスや指には筆圧がないので、かわりに動かす速さで太さが変わります(ゆっくり = 太い、速い = 細い)。

サイズと不透明度(サイドバー)

  • 上のバーを上下に動かすと、ブラシのサイズが変わります(1〜2000 px)。動かしている間、横に今の大きさ(px)が出ます。
  • その下のバーは不透明度(線の濃さ)です。
  • サイドバーのいちばん下の数字(%)は、キャンバスの拡大率です。画面を回しているときは、角度も出ます。押すと、全体を表示します。

好きなサイズを登録する

(登録のボタンを出す長押しは、少し長めです(約 0.7 秒)。好きな大きさに合わせている最中に、出てしまわないようにしています。)

よく使うサイズは、バーに目盛りとして残せます。

  1. サイズのバーを、残したい大きさに合わせます。
  2. そのままバーを長押しします(バーを動かして合わせたあと、指を離さずにそのまま止めているだけでも同じです)。横に「〇〇 px を登録」というボタンが出るので、押します。バーに青い目盛りが付きます。
  3. 次からは、バーをその近くに動かすと、目盛りの所でぴたっと止まります。

解除するときは、その大きさに合わせて(ぴたっと止めて)長押しし、「登録を解除」を押します。目盛りはブラシごとに覚えています。

スポイト(色を拾う)

  1. サイドバーのブラシを長押しします。ポインターがスポイトの形に変わります。
  2. 絵の、色を拾いたい所を押します。輪が出て、その場所の色になります。押したまま動かすと、動かした先の色に変わります。
  3. 離すと、自動でブラシに戻ります。

拾うのをやめるときは、ブラシのボタンをもう一度押します。

ブラシのウィンドウの上の帯にも、スポイトのボタンがあります(「＋ 新しいブラシ」のすぐ左)。押すと、同じようにスポイトになります。

長押しでスポイトにしたくないときは、設定の「ブラシのボタンの長押しで、スポイトにする」のチェックを外します(外すと、長押しはブラシの一覧になります)。

キーボードがあるときは、ブラシを使っている最中に Alt を押している間もスポイトになります。

キャンバスの長押しでも、色を拾えます(ブラシ・模様ペンのとき。「指で描く」をオフにしていても、指の長押しで拾えます)。ペンや指で絵を押したまま、動かさずに少し待つ(約 0.5 秒)と、輪が出て、その場所の色になります。そのまま動かすと、動かした先の色に変わります。離すと、ブラシのまま続けて描けます。使わないときは、設定の「キャンバスの長押しで、スポイトにする」のチェックを外します。

対称モード

そのほかの機能 → 対称モードを押すと、キャンバスのまん中を軸にして、映した所にも同時に描けます。押すたびに、左右 → 上下 → 4方向 → なし と切り替わります。軸は、ピンクの点線で出ます。ブラシと消しゴムに効きます。

図形

そのほかの機能 → 図形(キーボードは U)を選んで、キャンバスをなぞると、描画色で図形が描けます。

  • 図形のボタンをもう一度押すと、設定が出ます: 形(四角・楕円・直線・三角)、中を塗りつぶすか線だけか、線の太さ。
  • Shift を押していると、正方形・正円・45° ずつの線になります。

グラデーション

そのほかの機能 → グラデーションを選んで、押した所から離した所へなぞると、色がなめらかに変わる塗りになります。今のレイヤーの全体(選択範囲があれば、その中)に塗ります。

  • もう一度押すと、設定が出ます: 形(線形・円形)、色(描画色 → 背景色、描画色 → 透明)。

指先

そのほかの機能 → 指先を選んでなぞると、なぞった向きに絵がのびます(色をなじませる・ぼかす)。大きさと硬さは、ブラシで選んでいるブラシのもの(左のバー)です。もう一度押すと、強さを変えられます。

模様ペン(下の色に合わせて、線の色が変わる)

色の上に模様を描くためのツールです。サイドバーの、ブラシのすぐ下(ペンと波線の絵)にあります。 1本の線が、いくつかの色の上を通ると、通った所ごとに線の色が変わります。

選んでいる状態でもう一度押すと、設定が出ます。

設定 意味
線の色:下の色を暗く / 明るく(はじめ) 下の色を少し暗くした色で描きます。青の上では暗い青、緑の上では暗い緑になります。今の色(描画色)は使いません
線の色:明るさだけ合わせる 今の色の色み(赤っぽい・青っぽい、あざやかさ)のまま、明るさだけが下の色と同じになります
明るさの差 「下の色を暗く / 明るく」のとき、どれだけ変えるか。左へ動かすと暗く、右へ動かすと明るくなります(はじめは 15% 暗く)
何も描いていない所には描かない(はじめはオン) 絵のある所の上にだけ、線が出ます。色の外へはみ出しても、何もない所には付きません。外すと、何もない所は白い紙として描きます(「下の色を暗く」なら、うすい灰色)
  • 「下の色」は、描き始めたときに見えている絵(全部のレイヤーを重ねた色)です。別のレイヤーに描いても、下に見えている色に合わせます。
  • 「絵のある所」には、用紙(いちばん下の白い紙)は数えません。
  • 1本の線の中では、自分の線の上をもう一度通っても、さらに暗くはなりません。離してからもう一度描くと、その分だけ暗くなります。
  • 「明るさだけ合わせる」は、白の上では白、黒の上では黒になります(見えなくなります)。色の付いた所の上で使います。
  • 線の太さ・硬さ・不透明度は、ブラシで選んでいるブラシのものです(左のバーのサイズ・不透明度が、そのまま効きます)。鉛筆や水彩を選んでおけば、その描き味の模様ペンになります。

スタンプ

絵のほかの所を、写して描くツールです。

  1. そのほかの機能 → スタンプを選びます。
  2. 写したい元の所を、1回押します(コピー元。十字の印が付きます)。
  3. 写したい先をなぞると、コピー元のまわりの絵が、ずれを保ったまま写ります。
  • コピー元を選び直すには、スタンプのボタンをもう一度押して「コピー元を選び直す」を押します。キーボードがあるときは、Alt を押しながら押しても選び直せます。
  • 写すのは、今のレイヤーの絵です。大きさ・硬さ・不透明度は、ブラシで選んでいるブラシのものです。

テキスト

  1. そのほかの機能 → テキスト(キーボードは T)を選びます。
  2. 文字を入れたい所を押します。
  3. 文字・フォント・大きさ・太字 / 斜体を決めて、OK を押します。色は、今の描画色です。

文字は、新しいレイヤーになります(一覧の名前に Ｔ が付きます)。位置や大きさは、移動・変形のツールで変えられます。テキストのレイヤーを選んだままテキストツールで押すと、打ち直せます(打ち直すと、そのレイヤーに描き足した絵や、変形は消えます)。

まっすぐな線

線を引いたあと、Shift を押しながら別の所をクリックすると、前の線の終わりからそこまで、まっすぐな線が引けます。

3. ブラシを選ぶ・作る

サイドバーのブラシを、選んでいる状態でもう一度押すと、ブラシのパネルが出ます。

ブラシを選ぶ

一覧から押すだけです。左の絵は、そのブラシで引いた線の見本です。

ブラシ どんな線か
Gペン くっきりした線。筆圧で太さが大きく変わる(線画向き)
丸ペン 細くて固い線
鉛筆 紙のざらつきが出る線(下書き向き)
マーカー 太さが変わらない、半透明の線
筆(不透明水彩) やわらかいふちの、こってりした塗り
水彩 うすく重なる、ふわっとした塗り
エアブラシ 広くぼかして吹きつける(グラデーション・ほお紅)

消しゴムを長押しする(または選んでいる状態でもう一度押す)と、消しゴムの一覧(硬め・やわらかめ)になります。

新しいブラシを作る

  1. もとにしたいブラシを選びます。
  2. 右上の**＋ 新しいブラシ**を押します。同じ設定の「新しいブラシ 1」ができます。
  3. 下のこのブラシの設定で、名前と中身を好きに変えます。変えるたびに、一覧の見本の線も変わります。
設定 意味
サイズ 線の太さ
不透明度 1本の線の濃さの上限。同じ線の中で重ねても、これより濃くなりません
流量 重ねるほど濃くなる速さ。小さいと、少しずつ色が乗ります
硬さ ふちのくっきりさ。小さいほど、ふわっとぼけます
間隔 丸い判を押す間隔。大きくすると点々の線になります
丸さ 小さくすると、平たい筆になります
角度 平たい筆の向き
散らし 判をばらまきます(スプレー・葉っぱ・草のような線)
ざらつき 紙の目(鉛筆・パステルのような線)

自分で作ったブラシは削除できます。はじめからあるブラシは、設定を変えても初期設定に戻すでいつでも元に戻せます。

作ったブラシと変えた設定は、この端末に覚えているので、次に開いたときもそのままです(Windows と iPad では、別々に覚えます)。

ブラシの読み込み

ブラシのパネルの読み込み(または、そのほかの機能 → ブラシの読み込み)で、ブラシを足せます。

読み込めるもの どうなるか
Photoshop のブラシ(.abr) 中に入っている形が、1つずつブラシになります(1回に 40 個まで)
画像(PNG・JPEG など) 暗い所ほど濃い形のブラシになります。白い紙に黒で描いた絵を、そのままブラシの形にできます
  • 読み込んだブラシは、丸の代わりにその形を押していきます。「このブラシの設定」で、サイズ・間隔・角度・散らしなどを変えられます。
  • .abr で読めるのは、形を絵で持っているブラシです。Photoshop の中で計算して作る丸ブラシや、ブラシの動き方(散布・ゆらぎ・テクスチャなど)の設定は、読み込まれません。
  • 形は、256 px までに縮めて、この端末に覚えます。

線との隙間

パネルのいちばん下にあります。すでにある線から、決めた距離以内には色が乗らなくなる設定です(0〜100px)。

たとえば 20px にして、線の上からざっと塗ると、線のまわり 20px だけ塗り残されて、線と塗りのあいだに帯のような隙間ができます。

  • 同じ色にはくっつく(はじめはオン): 今の色と同じ色の所には、隙間をあけません。同じ色で何度かに分けて塗り足せます。外すと、どの色の線からも隙間があきます。
  • 隙間をあける相手は、用紙を除いた、見えているレイヤー全部の絵です。
  • 消しゴムには効きません。

4. バケツで塗る

サイドバーのバケツを選んで、塗りたい所を押します。見えている絵(線)を境目にして、今のレイヤーに色が入ります(境目にする絵は、設定で「今のレイヤーだけ」にもできます)。

線画のレイヤーの下に新しいレイヤーを作って、そこに塗るのがおすすめです。線がきれいに残ります。

バケツを長押しする(または選んでいる状態でもう一度押す)と、設定が出ます。

設定 意味
現在のレイヤーを参照 / キャンバスを参照 境目にする絵を選びます(どちらか1つ)。キャンバスを参照(はじめ)は、見えている絵ぜんぶ。線画が別のレイヤーにあっても、その線で止まります。現在のレイヤーを参照は、今のレイヤーの絵だけ。ほかのレイヤーの線は、ないものとして塗ります
隙間閉じ 線が完全にくっついていなくても塗れるようにします。線の切れ目が、ここで決めた幅より狭ければ、そこから外へもれません(0 = なし 〜 100px)
線へのはみ出し 塗る範囲をこの分だけ広げて、線の下にもぐらせます。線と塗りのあいだに白いすき間が残りません(0〜20px)
色の許容 大きいほど、似た色まで広く塗ります

コツ:

  • 外へもれるときは、隙間閉じを少しずつ大きくします。
  • 隙間閉じを大きくしすぎると、その幅より細い所(髪の先など)に塗り残しが出ます。もれない範囲で、いちばん小さい値にするのがおすすめです。
  • 線のきわに白い所が残るときは、線へのはみ出しを大きくします。線より大きくすると、線の向こう側まではみ出します。

5. レイヤー

右上の四角が重なったボタンで、レイヤーのパネルが出ます。上にあるものほど、手前に表示されます。

  • パネルの上の帯に、絵のボタンが並びます: 結合(下向きの矢印の下に、線が2本)・クリッピング(下へおりて右を向く矢印。クリップしている間は、オレンジ色になります)・グループ(フォルダ)・＋(新しいレイヤー)。その下は、ぜんぶレイヤーの一覧です。
  • レイヤーを選ぶ(押す)と、その行に欄が出ます: 大きい絵と、不透明度・重ね方・複製・ロック(鍵)・削除(ゴミ箱)。右にスライドすると、しまえます(ほかのレイヤーを選ぶと、また出ます)。左にスライドしても、出ます。欄を出している行は、名前・「空」の印・表示の丸を出さずに、大きい絵の横に欄だけを詰めて並べます。ボタンは1列です(名前と表示の切り替えは、欄をしまうと出ます)。
  • 欄に出すものと、その並びは、変えられます。 メニュー → レイアウト →「レイヤーの欄…」で、出すものにチェックを入れて、▲ ▼ で順番を決めます(不透明度・重ね方・重ね方の一覧・アルファロック・名前・複製・上へ / 下へ・グループの解除・マスクをクリップ・結合・消去・ロック・削除)。「レイヤーを選ぶと、その行に欄を出す」を外すと、左にスライドしたときだけ出ます。大きい絵の幅は、設定の「見た目」で変えられます。
  • ロックしているレイヤーには、名前の右に、灰色の鍵の印が出ます。
  • レイヤーの絵を消す(消去)ボタンは、パネルからはなくしました。3本指でこするか、Delete キー、または「そのほかの機能 → 消去」を使います。
  • 一覧が下まで入りきらないときは、右はしに細いスクロールバーが出ます。
  • 一覧は、レイヤーが増えると下へのびます。パネルが画面の下に届いたら、一覧の中をなぞって送ります。
  • 左の小さい絵は、レイヤー全体ではなく、描いてある所を大きく見せます(小さな部品でも、何が描いてあるか分かります)。
  • 何も描いていないレイヤーには、名前の右に「空」の印が出ます。
  • パネルを開いたまま、2本指のタップ(元に戻す)や、元に戻すボタンを押しても、パネルは閉じません。

順番を変える レイヤーを持って動かす(青い線の所に入ります)。指のときは、少し押してから動かします(すぐ動かすと、一覧のスクロールになります)

名前を変える 一覧で、すばやく2回押す

レイヤーをロックする

下のロックを押すと、そのレイヤーには、描く・動かす・消す・結合・削除ができなくなります(一覧の名前に 🔒 が付きます)。もう一度押すと、解除します。

レイヤーの絵を反転する

そのほかの機能 → レイヤーを左右反転 / 上下反転で、今のレイヤー(選択範囲があれば、その中)の絵そのものを反転します。見た目だけを反転したいときは、サイドバーのいちばん下の ◀▶ を使います。

画像を埋め込む

メニュー → 画像を埋め込む(または、そのほかの機能)で、画像のファイルを、新しいレイヤーとして置けます。キャンバスより大きい画像は、収まるように小さくして、まん中に置きます。置いたあとは、移動・変形のツールになるので、位置と大きさを決めます。

小窓と、右に固める

ブラシ・バケツ・レイヤー・色・色相彩度明るさ・シャープ・ノイズのウィンドウは、どれも次の3つの出し方ができます。

マスクをクリップ

マスクをクリップにチェックを入れると、そのレイヤーは、すぐ下のレイヤーに絵がある所にだけ表示されます。はみ出さずに影や模様を入れるのに使います。クリップしているレイヤーは、一覧の左に下向きの矢印とオレンジの線が付きます。チェックは、不透明度のバーの右にあります。

クリップしているレイヤーと、その土台のレイヤーの間に新しいレイヤーを作る(またはペーストする)と、新しいレイヤーも同じようにクリップされます(クリップしているレイヤーが1枚ふえます)。上のレイヤーのクリップ先が、途中で変わってしまうことはありません。

グループ

いくつかのレイヤーを、ひとまとめにできます。

  1. まとめたいレイヤーを選びます(まとめて選んでおくと、全部が1つのグループに入ります)。
  2. 右上のグループを押します。
  3. あとから入れるには、レイヤーを持って、グループの行の上で離します。出すには、グループの外の行まで持っていきます。
  4. グループの左の ▾ で、中身をたたんだり開いたりできます。中のレイヤーは、少し右にずれて表示されます。

グループを選ぶと、グループ全体の不透明度・重ね方・表示を変えられます。グループの中に、さらにグループは作れません(1段だけです)。

グループにもマスクをクリップできます。 グループのすぐ上のレイヤーで「マスクをクリップ」にチェックを入れると、グループの中の絵ぜんぶを合わせた形に、はみ出さずに描けます。上の画像では、色のグループに、乗算の影のレイヤーをクリップしています。

  • 結合: グループを選んで押すと、グループを1枚のレイヤーにまとめます。
  • グループをほどく「解除」ボタンは、設定で出せます。

はじめは隠してあるもの

次のものは、設定でチェックを入れると、レイヤーのパネルに出ます。

  • ほかの重ね方(スクリーン・オーバーレイなど 17 種類の一覧)
  • アルファロック: そのレイヤーの透明な所には描けなくなります。塗った形はそのままで、色だけを変えたいときに使います
  • 名前ボタン、▲ ▼ ボタン、グループの解除ボタン

6. 色

右上の丸いボタンで、色のパネルが出ます。

  • 大きな四角で、あざやかさと明るさを選びます。右の細い帯で、色あいを選びます。
  • 丸い形でも選べます。 設定の「見た目」→「色の選び方」を**丸(サークル)**にすると、まわりの輪で色あいを(赤が右上。そこから左回りに、黄・緑・青)、中の丸であざやかさ(右へ)と明るさ(上へ)を選ぶ形になります(左上が白、右上がその色、下が黒)。
  • 重なった2つの四角は、描画色(手前)と背景色(奥)です。奥の四角を押すと、入れ替わります(キーボードは X)。
  • 右下のパレットのボタン(四角が並んだ絵)で、履歴とよく使う色を、しまったり出したりできます。
  • 色のコード(#FF8800 など)の欄・⇄(入れ替え)・初期(黒と白に戻す)・CMYK の数字は、はじめは出していません。設定の「見た目」でチェックを入れると、出ます。
  • 履歴: 描いたり塗ったりした色が、新しい順に 10 個並びます。押すとその色になります。
  • よく使う色: 自分で色を並べておけるマス(30 個)です。
    • 空いたマスを押すと、今の色がそこに入ります。
    • 色の入ったマスを押すと、その色になります。
    • 長押しすると、今の色に入れ替わります(今の色と同じ色のマスなら、空に戻ります)。
  • 履歴とよく使う色は、この端末に覚えています。

絵の中の色を拾うには、ブラシを長押ししてスポイトにします。

仮想 CMYK(印刷の色の目安)

画面の色(RGB)には、印刷(CMYK のインク)では出せない、あざやかな色があります。そのほかの機能 → 仮想 CMYKを押すと、印刷したときの色に近づけて表示します(あざやかな緑・青・赤が、少しにぶく見えます)。

  • 変わるのは見た目だけです。絵そのものと、保存・書き出しの結果は、RGB のまま変わりません。
  • 設定で出していれば、色のパネルに、今の色を CMYK にしたときの数字(C・M・Y・K の %)が出ます。
  • どちらも目安です。印刷所の色の設定(プロファイル)を使った正確な変換ではないので、色に厳しい印刷物は、印刷所の指定に合わせて、Photoshop やクリスタで確かめてください。

7. 選択・移動と変形・コピー・絵の調整

トップバーのボタン(色相・彩度・明るさは、サイドバーのボタン)で行います。

選択(囲んだ所だけに効かせる)

  1. トップバーの選択を押します(キーボードは、M = 四角で囲む、L = なぞって囲む)。
  2. キャンバスをなぞって囲みます。離すと、白黒の点線の枠ができます。
  3. 囲み方は2つあります。選択のボタンをもう一度押すと切り替わります。
    • なぞって囲む(フリーハンド): 好きな形に囲めます
    • 四角で囲む
  4. 解除するには、選択ツールでキャンバスをタップします(キーボードなら Esc か Ctrl+D)。
  5. すべてを選択(Ctrl+A)と、選択範囲を反転(Ctrl+Shift+I)は、そのほかの機能にあります。
  6. 囲んだすぐあとなら、元に戻す(2本指のタップ・Ctrl+Z)でも解除できます。

囲んだ中に絵があるときは、離すと、そのまま移動・変形になります(枠とハンドルが出ます。下の「移動と変形」)。囲んだ中だけに塗りたいときは、そのあとブラシを選びます(選択範囲は残ります)。そのまま移動・変形にしたくないときは、設定の「囲み終わったら、そのまま移動・変形にする」のチェックを外します。

選択範囲があるあいだは、次のことがその中だけに効きます。

すること どうなるか
ブラシ・消しゴム・バケツ 枠の外にははみ出しません
移動・変形 枠の中の絵だけが、動く・大きさが変わる・回ります(枠もついていきます)
コピー 枠の中の絵だけをコピーします
色相・彩度・明るさ、シャープ、ノイズ 枠の中だけが変わります
消去 枠の中だけ消えます

移動と変形(大きさを変える・回す)

トップバーの移動・変形を選ぶと、今のレイヤーの絵(選択範囲があれば、その中の絵)のまわりに、枠が出ます。

やりたいこと 操作
動かす 枠の中(ハンドル以外の所)を持って動かします。Shift を押していると、縦か横だけに動きます
大きさを変える 角の丸を持って動かします。縦横の比はそのままです(下の帯の「縦横比を固定」を外すか、Shift を押していると、比を変えられます)。反対側の角は動きません
縦か横だけ伸ばす 辺のまん中の丸を持って動かします
回す 枠の上の緑の丸、または下の黄色の四角を持って、回します。Shift を押していると、15° ずつ回ります
  • 何回か続けて変えても、元の絵から描き直すので、絵が荒れていきません(ほかのツールに替えるか、ほかの操作をするまで)。
  • 1回ごとに、元に戻せます。
  • 絵のないレイヤーでは、枠は出ません。
  • 移動・変形のあいだは、選択範囲の点線は出しません(絵が見やすいように。選択範囲は、そのままあります)。

移動・変形のあいだ、画面の下に帯が出ます。

帯のボタン 意味
拡縮・回転 上の表の、動かす・大きさを変える・回す
自由変形 4つの角を、1つずつ好きな所へ動かせます(台形・ななめ・遠近のような形)。角以外の所を持つと、全体が動きます
メッシュ 4×4 の点が出ます。点を1つずつ動かして、絵を曲げます(なめらかに曲がります)
反転 左右 / 上下 枠の中の絵を、その場で反転します
縦横比を固定 角を持って大きさを変えるときに、縦と横の比を保ちます(はじめはオン)
完了 選択を解除して、前に使っていた描くツール(ブラシなど)に戻ります
  • キャンバスの外(まわりの暗い所)を押しても、完了になります(選択と移動・変形を、まとめて終わります)。選択ツールのままでも、同じです。「指で描く」をオフにしていても、指でタップすれば完了になります。
  • 拡縮・回転・自由変形・メッシュを切り替えると、そのときの絵から、枠を作り直します。
  • 自由変形・メッシュでゆがめた選択範囲は、点線ではなく、ふちの模様で表示されます。
  • メッシュの点を、となりの点を追いこすほど大きく動かすと、絵が折り重なります。

マスクモード(塗って選ぶ)

選択範囲を、ブラシで塗って作れます。

  1. そのほかの機能 → マスクモード(キーボードは Q)を押します。
  2. 選びたい所を、ブラシで塗ります。塗った所は、半透明の赤で見えます。消しゴムで減らせます。バケツや図形も使えます。
  3. もう一度マスクモードを押すと、塗った所が選択範囲になります。
  • 入るときに選択範囲があれば、その形から始まります(選択範囲を、塗って足したり、消しゴムで削ったりできます)。
  • やわらかいブラシで塗ると、ふちがぼけた選択範囲になります。

切り抜き

  1. そのほかの機能 → 切り抜き(キーボードは C)を選びます。選択範囲があれば、その範囲から始まります。
  2. キャンバスをなぞって、残したい範囲を囲みます(Shift で正方形)。外側が暗くなります。
  3. 下に出る切り抜くを押します(キーボードは Enter)。全部のレイヤーが、その範囲に切り抜かれます。元に戻せます。

コピーとペースト

  • コピー: 今のレイヤーの絵(選択範囲があれば、その中だけ)を取っておきます。
  • ペースト: 取っておいた絵を、同じ位置に、新しいレイヤーとして貼ります。貼ると、画面の下に「ペーストしました」と出ます。

キャンバスのコピー

今見えている絵ぜんぶを1枚にまとめて、新しいレイヤーとしていちばん上に足します(用紙の白は入りません)。元のレイヤーはそのまま残ります。足すと、画面の下にメッセージが出ます。

色相・彩度・明るさ

今のレイヤー(選択範囲があれば、その中)の色を変えます。

  1. サイドバーの色相・彩度・明るさ(バケツの下)を押します。
  2. 3本のバーを動かすと、その場で絵の色が変わります。バーの色は、そこまで動かしたらなる色です(まん中が今の色。絵の平均の色をもとにしています)。
    • 色相: 色あいを回します(赤 → 黄 → 緑 …)
    • 彩度: あざやかさ
    • 明るさ
  3. 適用で確定、やめるで元に戻します。

レベル補正

そのほかの機能 → レベル補正で、今のレイヤー(選択範囲があれば、その中)の明るさの幅を整えます。上のグラフは、明るさの分布です(左 = 暗い、右 = 明るい)。

バー 意味
入力: 黒 これより暗い所を、まっ黒にします。右へ動かすと、暗い所がしまります
入力: 中間 中間の明るさ。大きいほど、全体が明るくなります
入力: 白 これより明るい所を、まっ白にします。左へ動かすと、明るい所がとびます
出力: 黒・白 いちばん暗い所・明るい所を、どの明るさにするか(幅をせばめて、うすくする)

うすい鉛筆の線をくっきりさせるときは、「入力: 白」を左へ、「入力: 黒」を右へ寄せます。適用で確定、やめるで元に戻します。

シャープとノイズ

トップバーのシャープ・ノイズを押すと、ウィンドウが出ます。今のレイヤー(選択範囲があれば、その中)に効きます。

  • シャープ: 輪郭をくっきりさせます。バーは3つです。
    • 強さ(0〜300%): くっきりさせる強さ
    • 半径(1〜40 px): どのくらいの太さの輪郭に効かせるか。小さいと細かい線や髪の毛、大きいと大きな明暗がはっきりします
    • しきい値(0〜60): まわりとの差がこれより小さい所は、そのままにします。大きくすると、なめらかな塗りやざらつきは変えずに、はっきりした輪郭だけを強めます
  • ノイズ: 絵のある所に、ざらざらを足します。「量」のバーで加減します。「色つきのノイズ」にチェックを入れると、色のついた粒になります(外すと、明るさだけが変わります)。

どちらも、バーを動かすとその場で絵が変わります。適用で確定、やめるで元に戻します。

iPad(ブラウザ)では、保存した絵は Kaiju フォルダ(iPad の中の、Kaiju のフォルダ)に入ります。

  • 保存: はじめて保存するときと「名前を付けて保存」では、名前と形式を聞きます。2回目からは、同じ名前に上書きします。
  • 開く: Kaiju フォルダの絵が、新しい順に並びます。選んで「開く」。
    • 「ファイルから開く…」: 「ファイル」アプリにある PSD・.kaiju(Windows で保存したものなど)を開きます。
    • 「書き出す」: 選んだ絵をファイルにして、「ファイルに保存」(iCloud Drive など)・AirDrop・ダウンロードで出します。Windows に渡すときや、控えを取るときに。
    • 「消す」: Kaiju フォルダから消します(元に戻せません)。
  • 「名前を付けて保存」の「保存する所」を「ファイルに書き出す」にすると、Kaiju フォルダには入れずに、ファイルとして出します(次の「保存」も同じ)。
  • Kaiju フォルダは、iPad の「ファイル」アプリからは見えません(Safari で動くアプリは、「ファイル」の中にフォルダを作れないためです)。
  • 大事な絵は、ときどき「書き出す」で控えを取ってください。ホーム画面に追加していない Safari は、長く(1週間ほど)開かないと、Kaiju フォルダの中身を消すことがあります。ホーム画面に追加して使うと、消されにくくなります。
  • 「ファイル」アプリに Kaiju のフォルダを作って、そこに書き出したいとき: 「ファイル」アプリで「このiPad内」(か iCloud Drive)に「Kaiju」フォルダを作り、iPad の設定 → アプリ → Safari →「ダウンロード」で、そのフォルダを選ぶと、ダウンロードがそこに入ります(Kaiju からは、この設定を変えられません)。

保存のフォルダ(Windows 版)

保存した絵は、1つのフォルダにどんどんたまっていきます。

  • はじめは ドキュメント\Kaiju。フォルダは、はじめて保存したときに1回だけ作ります
  • **新しい絵の「保存」**は、画面を出さずに、このフォルダへ「無題_日付-時刻.psd」(形式は設定のもの)の名前ですぐ保存します。同じ名前がもうあれば「(2)」を付けます。名前を付けたいときは「名前を付けて保存」
  • 開く・PNG で書き出しなどの画面も、このフォルダから始まります
  • 設定 →「保存」で変えられます(下の 10章)
  • iPad(ブラウザ)は、Kaiju フォルダです(上)

ほかの端末と共有する(共有パック)

Windows と iPad の間などで、描いている絵(レイヤーごと)と、設定(ブラシ・バーの並び・色・パレットなど)を受け渡せます。アカウントはいりません。 絵と設定を1つのファイル(共有パック。名前.kaijushare.json)にして、iCloud Drive・OneDrive など、両方の端末から見えるフォルダや、AirDrop で運びます。

送る: メニュー →「共有パックを送る…」(「そのほかの機能」や、レイアウトでバーに置いたボタンからも)

  1. 名前を決めて、送るもの(描いている絵 / 設定)にチェックを入れて、「送る」を押します。
  2. iPad: Kaiju の中の共有フォルダに入ります。ほかの端末(Windows など)へも送るときは、続けて「共有する」を押すと、共有の画面が出ます。「ファイルに保存」で iCloud Drive などに入れるか、AirDrop で送ります(共有の画面が使えないときは、「ダウンロードで保存」)。
  3. Windows: 共有フォルダに、そのまま入ります。共有フォルダは、はじめて使うときに自動で作ります(iCloud Drive の中の「Kaiju 共有」。iCloud Drive がなければ OneDrive の中、それもなければ ドキュメントの中)。iCloud Drive か OneDrive の中なら、iPad の「ファイル」からも見えます。「変える…」で、ほかのフォルダにもできます。

開く: メニュー →「共有パックを開く…」

  1. iPad: Kaiju の中の共有フォルダの共有パックが、新しい順に並びます。選んで「開く」。ほかの端末から送ったものは「ファイルから取り込む…」で選びます(取り込んだものは、Kaiju の中の共有フォルダにも入るので、次からは一覧から開けます)。いらなくなったものは「消す」。
  2. Windows: 共有フォルダの中の共有パックが、新しい順に並びます。選んで「開く」。ほかの場所のファイルは「ほかの場所から…」。
  3. 入れるもの(絵を開く / 設定を入れる)を選んで、「入れる」を押します。
  • 絵を開くと、今の絵と入れ替わります(保存していないときは、そう出ます)。開いた絵は「無題」になるので、残すときは保存してください。
  • 設定は、その場で入れ替わります。小窓の位置と「指で描く」は、端末ごとにちがうので、受け渡しません。
  • 大きい絵(A4 でレイヤーが多いなど)は、ファイルが大きくなります(数十 MB)。
  • iPad の「Kaiju の中の共有フォルダ」は、iPad の「ファイル」アプリからは見えません(Safari で動くアプリは、「ファイル」の中にフォルダを作れないためです)。ほかの端末とは、共有の画面と「ファイルから取り込む…」でやりとりします。
  • iPad で「ファイルから取り込む…」を押すと、前に開いたフォルダが出ることが多いです。1回、Windows の共有フォルダ(iCloud Drive / OneDrive の「Kaiju 共有」)を開いておくと、次から探しやすくなります。

iPad で、ネットがなくても使う(オフライン)

iPad 版は、1回開けば、次からはネットがなくても起動できます。開いたときに、中身を iPad の中に取っておくためです。

  1. ネットにつながっている状態で、Safari で Kaiju を開きます。少しすると「オフラインでも使えるようになりました」と出ます(メニューのいちばん下にも「オフラインで使えます」と出ます)。
  2. 共有ボタン →「ホーム画面に追加」をしておきます。次からは、ホーム画面のアイコンから開きます。
  3. これで、機内モードや電波のない所でも、同じように開いて描けます。保存や書き出しも、いつもどおり iPad の中にできます。
  • 新しい版にするには: **メニュー →「新しい版を確かめる(更新)」**を押します(「そのほかの機能」や、レイアウトでバーに置いたボタンからも)。新しい版があれば、取ってきて、画面を読み込み直します。いちばん新しい版のときは、そう出ます。
    • 保存していない絵があるときは、読み込み直す前に聞きます(読み込み直すと、保存していない絵は消えます)。先に保存してから押すと安心です。
    • ネットにつながっている状態で開き直す(Safari の更新)でも、新しい版になります。
    • Windows 版は、新しい Kaiju.exe を開くと新しい版になります(このボタンを押すと、今の版を知らせます)。
  • ブラシの設定や作ったブラシは、iPad の中に覚えています。
  • 長いあいだ(数週間)開かないでいると、iPad が取っておいた中身を消すことがあります。そのときは、ネットにつながっている状態でもう一度開いてください。
  • 描いた絵は、自動では残りません。保存して、ファイルとして残してください。

10. 設定

メニュー →**設定…**で開きます。

保存

  • 保存の形式: PSD(はじめ)か、Kaiju の形式(.kaiju)。
  • 保存のフォルダ(Windows 版): 今のフォルダの表示、フォルダを変える… / はじめのフォルダに戻す / フォルダを開く(エクスプローラーで)。
  • 「開く」で、まず見る所(Windows 版): 保存のフォルダ(はじめ)/ 前に開いた所。

レイアウト(ボタンの位置を変える)

  • 下の箱には、置けるものが、いつも全部並んでいます。同じボタンを、いくつ置いてもかまいません(サイズと不透明度のバーだけは、1つずつです)。
  • 箱は、指でなぞっても送られません(なぞると、ボタンを持つことになります)。箱の続きを見るには、帯の ▲ ▼ を押します。
  • 帯の「レイヤーの欄…」で、レイヤーを選んだときに出る欄の中身を、「色とデザイン…」で、色や素材を変えられます。
  • チャーム(リボンの絵のボタン。はじめは「そのほかの機能」の中。バーにも置けます): ボタンの絵を、自分の好きな画像に変えられます。 一覧から変えたいボタンの「画像を選ぶ」を押して、画像を選びます(まわりが透明な PNG が向いています。96 px までに小さくして、この端末に覚えます)。「戻す」で、はじめの絵に戻ります。サイズ・不透明度のバーのつまみの絵も、ここで選べます。
  • 文字だけだったボタン(左右反転・複製・結合・CMYK など)は、ぜんぶ絵のボタンになりました。押し続ける(マウスなら、上に置く)と、名前が出ます。

トップバーとサイドバーに並ぶものは、どれも、持って好きな所へ動かせます。トップバーのボタンをサイドバーへ、サイドバーのボタンをトップバーへ移すこともできます。

  1. **メニュー →「レイアウト」**を押します(Windows 版は、上のメニューの「ヘルプ」の横の「レイアウト」からも)。
  2. 動かせるものに点線の枠が付き、下に箱が出ます。この間は、ボタンを押しても働きません。
  3. ボタンを持って、置きたい所で離します。青い線の所に入ります。
  4. 終わったら、箱の完了を押します。
やりたいこと やり方
並べ替える・別のバーへ移す 持って、置きたい所で離す
バーから外す 持って、下の箱に入れる
置いていないボタンを足す 下の箱から持ってきて、置く
元に戻す 箱の「はじめの並びに戻す」
  • 箱には、はじめは並んでいないボタンもあります: 重ね方の切り替え(通常 ⇄ 乗算)、マスクをクリップ、レイヤーの複製・結合・削除、グループにする、カット、スポイト、設定 など。
  • 区切りの線とすきまは、いくつでも置けます。すきまは、残りの幅(サイドバーでは高さ)を埋めます。レイヤーと色のボタンが右はしにあるのは、その左にすきまがあるからです。
  • サイズと不透明度のバーは、サイドバーの中で動かせます(トップバーには置けません)。
  • 「メニュー」のボタンだけは、動きません。

自分で変えた並びは、アップデートしても、そのまま残ります。

  • 並びを変えていない人は、アップデートのたびに、その版のはじめの並びになります(新しいボタンが増えれば、そのまま出ます)。
  • 並びを変えた人は、こちらから並びを変えません。アップデートで機能が増えたときは、起動のときに「新しい機能が増えました」と知らせ、増えた機能は「そのほかの機能」とレイアウトの箱に入ります。
  • 「…(そのほかの機能)」のボタンをバーから外していても、メニュー → そのほかの機能から開けます。
  • 「はじめの並びに戻す」を押すと、また、その版のはじめの並びについていくようになります。
  • 並びは、端末ごとに覚えています(Windows と iPad は別々)。**設定 →「設定を書き出す」**でファイルにしておくと、控えになり、ほかの端末で「設定を読み込む」こともできます。
  • iPad の Safari は、長いあいだ(1週間ほど)開かないと、覚えた設定を消してしまうことがあります。ホーム画面に追加して使うと、消されにくくなります。大事な並びやブラシは、設定を書き出しておくと安心です。

設定の書き出し / 読み込み

設定の「ボタンの並びと、設定の控え」にあります。ボタンの並び・ブラシ(作ったもの・読み込んだもの)・よく使う色・メッセージの文言などを、1つのファイルにします。読み込んだ設定は、Kaiju を開き直すと変わります。

レイヤーのパネル

  • 重ね方のボタンで切り替える2つ: 重ね方のボタンを押すたびに切り替わる2つを選びます(はじめは 通常 と 乗算)。
  • ほかの重ね方の一覧、アルファロック、名前・▲▼・解除 のボタンを出すかどうか。

新規作成と、よく使うサイズ

メニュー →新規作成で、キャンバスの大きさを決めて、新しい絵を始めます。

  • 上に並んだボタンが、よく使うサイズです。押すと、その幅と高さになります。
  • 登録: 幅と高さを入れて(名前は、なくてもかまいません)、＋ このサイズを登録を押します。
  • 削除: ボタンの右の × を押します。
  • はじめに戻すで、はじめの一覧に戻ります。
  • 登録したサイズは、この端末に覚えています。
  • 起動したときのキャンバスの大きさは、設定 →「保存」の「起動したときのキャンバス」で変えられます(新規作成のはじめの値にもなります)。

見た目

  • 画面の色合い: 標準 / 暗い / もっと暗い(黒)。どれも、上と左右のバーは、キャンバスのまわりより暗い色です。
  • 左利きモード(サイドバーを右に): オンにすると、サイドバー(ブラシ・消しゴム・サイズ・不透明度など)が右の端に、「右に固める」にしたウィンドウが左の端に移ります(左右が入れ替わります)。ブラシのパネルなども、右から出ます。左手でペンを持つときに。
  • 左のバーのボタン: 小 / 中 / 大。ブラシ・消しゴムなどのボタンと絵の大きさが変わります(左利きモードでは、右のバー)。
  • 色の選び方: 四角(はじめ)/ 丸(サークル)。
  • 色のパネルに、入れ替え(⇄)・初期・色のコード(#)・CMYK の数字を出す: はじめは出していません。
  • 描画色・背景色の四角に、白いふちを付ける: はじめは付けていません。
  • レイヤーの大きい絵: レイヤーを左にスライドしたときに出る絵の幅(48〜220 px。はじめは 96 px)。

色とデザイン(レイアウトの帯の「色とデザイン…」からも開けます)

  • 素材とチャームは、小さくして(素材は 512 px まで、チャームは 128 px まで)、この端末に覚えます。

操作

  • ブラシのボタンの長押しで、スポイトにする: はじめはオンです。オフにすると、ブラシを長押ししたときに、スポイトではなくブラシの一覧が出ます。
  • キャンバスの長押しで、スポイトにする: はじめはオンです。ブラシ・模様ペンで、絵を押したまま動かさずに少し待つと、色を拾います。
  • 囲み終わったら、そのまま移動・変形にする: はじめはオンです。オフにすると、囲んだあとも選択ツールのままです。
  • 手ぶれ補正の強さ: 全部のブラシの「手ぶれ補正」に掛ける倍率です(なし〜×10。はじめは ×3)。大きいほど線がなめらかになり、その分、ペンに遅れてついてきます。
  • 指で描く: オフにすると、指では描かず、ペンだけで描きます。
  • 回転が 0° に戻る角度: 画面を回しているとき、0° からこの角度以内なら、自動で 0° に戻ります。0 にすると戻りません。

メッセージ(画面の下に出る文言)

「ペーストしました」「保存しました」など、何かしたときに画面の下に出るメッセージの文言を、好きに変えられます。

  1. 「文言を変える」を押して開きます。
  2. 変えたいメッセージの欄に、新しい文言を入れます。うすい字は、はじめの文言です。空のままなら、はじめの文言のままです。
  3. {size} や {name} と書いた所には、そのときの数字や名前が入ります。

13. Claude と連携する(Windows 版)

Claude(Claude Code)に、Kaiju で絵を描いてもらえます。下描き → 線画 → 色塗り → 影と光 → 保存 まで、Claude が自分で線と面を置いていきます(画像を作る AI ではなく、ブラシ・バケツ・形で描きます)。

使い方

  1. はじめに1回だけ、Claude に Kaiju を登録します(Claude Code で、次の1行を実行します。フォルダの場所がちがうときは、合わせてください)。

    claude mcp add --scope user kaiju -e ELECTRON_RUN_AS_NODE=1 -- "C:\Users\ケータロー\Desktop\Kaiju\node_modules\electron\dist\electron.exe" "C:\Users\ケータロー\Desktop\Kaiju\lib\mcp-bridge.js"

  2. Claude に、「Kaiju で、りんごの絵を描いて」のように頼みます。Kaiju が閉じていれば、自動で開きます。

  3. Claude が描いている間、Kaiju の画面で、絵ができていくのが見えます。レイヤーは「下描き」「線画」「色」「影」のように分かれるので、あとから自分で手直しできます。

Claude ができること

すること 中身
見る 今の絵を画像で見る(全体・一部の拡大・レイヤー1枚だけ・座標の目盛りつき)
レイヤー 足す・選ぶ・名前・不透明度・重ね方・マスクをクリップ・アルファロック・表示・削除・複製・結合・消去・上下
ブラシで描く ブラシ・色・太さ・不透明度を選んで、線を引く(入り抜きつき)。消しゴムも
バケツで塗る 線で囲んだ中を塗る(隙間閉じ・線へのはみ出しも使えます)。何か所も、まとめて塗れます
形で塗る 多角形・なめらかな形・楕円・四角・パスを、塗り・線・ぼかしつきで描く(影や光に)
左右対称 線・形・バケツを、縦の線で映して、左右に同じように描く(正面を向いた人や顔に)
選択範囲 形で囲む・同じ色の所を選ぶ(自動選択)・レイヤーの絵のある所を選ぶ。足す・引く・反転・ふちをぼかす。選んだ所にだけ描けます
動かす・変形 レイヤーの絵(選択範囲があれば、その中だけ)を、動かす・大きさを変える・回す・反転する
色の調整 色相・彩度・明るさを変える(色違いを作る)
元に戻す Claude が描いたものも、1つずつ元に戻せます(自分で、2本指タップや Ctrl+Z でも)
画像を置く 画像のファイルを、新しいレイヤーとして置く(資料・下絵)
保存 PSD で保存、PNG で書き出し(背景なし・絵の大きさに切りつめる・縮める もできるので、ゲームの素材にそのまま使えます)
  • Claude は、あなたのブラシの設定・今の色・今のツールを、変えません(描く間だけ借りて、戻します)。
  • 保存していない絵があるとき、Claude は、勝手に新しい絵を始めません(あなたに確かめます)。
  • Claude が選択範囲を作ると、画面にも点線が出ます。Claude が解除し忘れていたら、選択ツールでキャンバスをタップするか、Esc(Ctrl+D)で解除できます。
  • Claude が描いた線1本・形1回・バケツ1回が、元に戻すの1回分です。元に戻せるのは 60 回までなので、Claude がたくさん描くと、その前の自分の操作は、戻せなくなります。
  • つながるのは、この PC の中だけです(ほかの PC やインターネットからは、つながりません)。
  • iPad 版(ブラウザ)では、使えません。
